# GitHub Docs Arabic Enhanced

هذا المشروع هو نسخة محسنة من وثائق GitHub باللغة العربية، تم تحديثه ليشمل أحدث التقنيات والتحسينات.

## التغييرات والتحسينات

### 1. التحديثات التقنية
*   **React 19**: تم تحديث React و ReactDOM إلى أحدث إصدار مستقر (v19) للاستفادة من أحدث الميزات وتحسينات الأداء.
*   **TypeScript**: تم تحديث تعريفات الأنواع (`@types/react`, `@types/react-dom`) لتتوافق مع الإصدار الجديد.
*   **Next.js**: المشروع يعمل على إصدار حديث من Next.js لضمان أفضل أداء وتجربة مستخدم.

### 2. تحسينات الأداء
*   **Image Optimization**: تحسين تحميل الصور لتقليل وقت تحميل الصفحة.
*   **Font Optimization**: استخدام خطوط محسنة لتقليل وقت العرض الأول (FCP).

### 3. تحسينات التصميم (مخطط لها)
*   **UI/UX**: تحسين واجهة المستخدم لتكون أكثر عصرية وسهولة في الاستخدام.
*   **Dark Mode**: دعم كامل للوضع المظلم.

## كيفية التشغيل

1.  تثبيت الاعتماديات:
    ```bash
    npm install
    ```

2.  تشغيل خادم التطوير:
    ```bash
    npm run dev
    ```

3.  بناء المشروع للإنتاج:
    ```bash
    npm run build
    ```
